# Devo

> Devo is a cloud-native security data platform delivering unified SIEM, security analytics, and threat detection at petabyte scale, powered by its HyperStream data engine. Devo exposes a public REST API surface — a Query API (synchronous and asynchronous job-based queries), an Alerts API, plus Activeboards, Lookups, Provisioning, and Relay APIs — with regional endpoints for the US (apiv2-us.devo.com) and EU (apiv2-eu.devo.com). Authentication uses domain API key + secret HMAC-SHA256 signing or a standalone Bearer token.

## APIs

- [Devo Query API](https://docs.devo.com/space/latest/95128275/Query+API): Run synchronous or asynchronous (job) queries against ingested data; base https://apiv2-us.devo.com (US) / https://apiv2-eu.devo.com (EU).
- [Devo Alerts API](https://docs.devo.com/space/latest/95128644): Manage alert definitions and instances; base https://api-us.devo.com/alerts.
- [Devo Activeboards API](https://docs.devo.com/space/latest/95128251/API+reference): Manage Activeboards (dashboards).
- [Devo Lookups API](https://docs.devo.com/space/latest/95128251/API+reference): Manage lookup tables.
- [Devo Provisioning API](https://docs.devo.com/space/latest/95128251/API+reference): Administrative provisioning of domains, users, and resources.
- [Devo Relay API](https://docs.devo.com/space/latest/95128251/API+reference): Manage Relay configuration for secure data forwarding.
